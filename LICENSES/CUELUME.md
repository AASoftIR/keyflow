# Cuelume attribution

Keyflow uses the `cuelume` project as its primary interaction/typing sound palette.

- Project: https://github.com/danielwh2/cuelume
- Package: https://www.npmjs.com/package/cuelume
- Version pinned by this project: 0.2.4
- License: MIT

Cuelume synthesizes interaction sounds live through the Web Audio API. Keyflow does not bundle prerecorded sound files from Cuelume.
